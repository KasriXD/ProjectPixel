# LeakSanitizer suppressions for allocations we do not own.
# Keep this list minimal and explain every entry.

# Mesa's EGL library keeps a one-time allocation made when SDL's offscreen video
# driver initialises EGL (seen with SDL 3.4.18 + Mesa 25.2 on Ubuntu 24.04).
leak:SDL_EGL_InitializeOffscreen

# Driver-internal allocations owned by the EGL context above, made while SDL's
# software renderer presents through its internal window-texture path. No
# engine code allocates below this frame.
leak:SDL_UpdateWindowTexture
